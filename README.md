# GoldBlock 💳

GoldBlock is a modern mobile banking application built with **Expo, React Native, and TypeScript**.

The application provides a digital banking experience with features such as user authentication, banking screens, and virtual card functionality. Firebase is used to provide backend and authentication services.

## 📱 Features

- 🔐 User authentication
- 🏦 Digital banking interface
- 💳 Virtual card creation and management
- 🔥 Firebase integration
- 📱 Android application
- ⚡ Modern and responsive mobile UI
- 🧩 Reusable React Native components and context-based state management

## 🛠️ Tech Stack

- **React Native**
- **Expo**
- **TypeScript**
- **Firebase**
- **JavaScript**
- **Android**
